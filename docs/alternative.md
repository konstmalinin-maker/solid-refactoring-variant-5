# F. Два самостоятельных дизайна

Основной: DocumentService/Queries/VersionService, Strategy экспортёров, узкие порты.
Альтернатива: independent functions в alternative/operations.py и dispatch table
функций экспорта в alternative/exports.py. Она не вызывает основной DocumentService
или ExportService. Общие модели, валидация и адаптеры I/O включены в обе области
измерения, а не объявлены «бесплатными» строками.

| Метрика | Strategy + ports | Functions + dispatch |
|---|---:|---:|
| CC | 1.373 | 1.5 |
| Weighted MI | 67.3672 | 63.8347 |
| Классов | 27 | 12 |
| SLOC | 248 | 181 |

Один неизменный набор из 23 характеризующих тестов проходит на обоих дизайнах.
Scope и сырые результаты — alternative-comparison.json. Дополнительный read-only
клиент выделен в основном варианте, поэтому сравнение не трактуется как равенство
всех внутренних возможностей до последнего типа.

Для текущего небольшого API функциональный вариант проще: меньше классов и SLOC.
Основной вариант удобнее при независимом росте экспортёров и адаптеров. Для учебной
отработки всех пяти принципов основным оставлен Strategy/ports; в небольшом рабочем
проекте разумно начать с функций и добавлять объекты при появлении такой потребности.
