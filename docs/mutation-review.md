# Мутационное тестирование и разбор

Mutmut 3.3.1, весь исполняемый код src/solid, без do_not_mutate и без pragma
no mutate. src/compat.py — только импорт для старого публичного пути, бизнес-логики
в нём нет. Стандартный src-layout устраняет конфликт mutmut с пакетом по имени src.
Исходный legacy и tests_before не менялись.

Первый полный прогон: 496 мутантов, 465 killed, 31 survived (6,25%).
После точной проверки сообщений об ошибках: 496 мутантов,
469 killed, 27 survived
(5.4435%). Нет timeout, skipped, no-tests и not-checked.
GitHub Actions независимо повторил полный прогон с теми же числами.

Слабый эксперимент: тот же discounts.py скопирован байт-в-байт. Один smoke-тест
исполняет 100% строк, но не проверяет суммы: 6 мутантов,
4 killed, 2 survived
(33.33%). Это демонстрирует, что даже 100% строк (выше 85%)
не гарантируют качество проверок.

## Найденный полезный дефект тестов

pytest.raises(..., match="document not found") допускает сообщение
XXdocument not foundXX. Новые tests_after/test_error_contracts.py сравнивают
exception.args целиком. Характеризующие тесты оставлены без изменений.
Убиты ещё четыре мутанта сообщений об ошибках.

## Репрезентативные оставшиеся случаи

- ensure_ascii=False → None: обе настройки ложны для json.dumps и дают тот же результат.
- sum(..., Decimal(0)) → sum(...): для непустых валидных Decimal-позиций результат тот же;
  пустой Order запрещён объектом.
- Части мутаций оформления JSON-хранилища не изменяют чтение логических документов.

Это разбор примеров, а не заявление, что все 27 мутантов эквивалентны. Оставшийся
процент показывает ограничения тестов. Список каждого surviving ID сохранён в
mutation-full.json; исключениями или ручной правкой результатов порог не достигался.

Команды: `mutmut run --max-children 2`, затем
`python scripts/mutation_summary.py --output docs/mutation-full.json --gate`.
