# Самопроверка перед merge

Работа индивидуальная; независимого одногруппника нет. Внешнее ревью и чужое
одобрение GitHub не имитируются. Это ограничение отдельно указано в отчёте.

Проверено:
- Пять рабочих коммитов рефакторинга, после каждого 23 исходных теста проходят.
- Legacy, conftest и tests_before байт-в-байт совпадают с исходным коммитом.
- Отказ чтения текста у скана сохранён на границе API; сам скан больше не наследует текстовый контракт.
- Domain/application не импортируют legacy и инфраструктуру.
- Расширение формата MD и новой политики teacher не изменяет сервисы.
- Подмена репозитория через DI-контейнер восстанавливается даже при исключении.
- Мутации выявили неполноту regex-проверок ошибок; добавлены точные сравнения args.
- Реальные ранги Radon не подменены буквами из примерной таблицы.
- Отдельный expected-failure workflow действительно отвергает исходный MI.
- Альтернатива реализует use cases независимо; общие адаптеры учитываются в метриках.
- Бенчмарк проверяет равенство результата, производительность измерена, ухудшение заказного примера объяснено.

Ссылки на CI и исходные артефакты сохранены в docs/evidence.
